# C++ 示例

这是一个简单的 C++ 示例程序，展示了 C++ 的基本特性。

## 文件说明

- `hello.cpp` - 主程序文件，包含以下功能：
  - 基本的输入输出操作
  - 函数定义和调用
  - STL 容器（vector）的使用
  - 范围 for 循环
  - 用户交互

## 编译和运行

### 使用 g++

```bash
# 编译
g++ -std=c++11 -o hello hello.cpp

# 运行
./hello
```

### 使用 clang++

```bash
# 编译
clang++ -std=c++11 -o hello hello.cpp

# 运行
./hello
```

### Windows (使用 MSVC)

```cmd
# 编译
cl /EHsc hello.cpp

# 运行
hello.exe
```

## 程序功能

1. **问候函数** - 接受一个字符串参数并输出问候语
2. **求和函数** - 计算整数向量中所有元素的和
3. **用户交互** - 从标准输入读取用户名并进行问候

## 代码特点

- 使用 C++11 标准
- 遵循现代 C++ 最佳实践
- 代码简洁易懂
- 包含中文注释和输出
